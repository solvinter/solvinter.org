# Solvinter.org — first static prototype

A zero-build static prototype for the Solvinter website.

## Preview locally

From this folder:

```sh
python3 -m http.server 4173
```

Then open:

http://127.0.0.1:4173/

## Structure

- `index.html` — main site
- `styles.css` — visual system
- `script.js` — lightweight reveal interaction
- `assets/images/` — curated Ghana photographs

No original source photographs are modified.
